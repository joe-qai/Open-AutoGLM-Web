快速开始

三个命令，快速启动。

后端、前端、CLI，三选一，无需复杂配置。

第一步

启动后端

# 端口 8005
cd backend
pip install -r reqs.txt
python run.py
第二步

启动前端

# 代理 API → :8005
cd frontend
npm install
npm run dev
第三步

运行任务

python main.py \
  --base-url <URL> \
  --model <NAME> \
  "打开美团搜索火锅"
